
# Smart City Route Navigation System

A web-based navigation project designed to help users search for locations and visualize road routes.

## Technologies Used

- HTML5, CSS3, JavaScript, Bootstrap
- Python Flask
- MySQL
- Leaflet.js
- OpenStreetMap
- Nominatim
- OSRM
- Chart.js

## Features

- Interactive map
- Start and destination location search
- Road route visualization
- Route history
- User login and registration
- Dashboard and reports
- Traffic information integration
- Route-planning algorithm demonstration

## Installation

1. Install Python and MySQL.
2. Create the database and required tables.
3. Configure your local environment variables using `.env.example`.
4. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the application:

   ```bash
   python app.py
   ```

6. Open `http://127.0.0.1:5000/` in your browser.

## Security

Never upload `.env`, passwords, API keys, or OAuth secrets to GitHub.
