🧠 Four Ways to Find a Route

Each algorithm follows a different method to explore possible paths.

BFS

Breadth First Search

Checks nearby locations first and then moves to the next level of locations.

🟢 → 🔵 → 🔵 → 🔵
Simple idea: Explore nearby roads first.

DFS

Depth First Search

Follows one possible path deeply before coming back and trying another path.

🟢 → 🔵 → 🔵 → 🎯
Simple idea: Follow one road deeply.

Best First

Best First Search

Gives priority to the location that appears closest to the destination.

📍 → 🛣️ → 🎯
Simple idea: Move towards the destination.
⭐ RECOMMENDED

A* Search

A-Star Algorithm

Considers both the distance already travelled and the estimated distance to the destination.

📍 → 🛣️ → 🛣️ → 🎯
Simple idea: Try to find an efficient route.

⭐ Which algorithm should I choose?

Don't worry about the technical names. Here is the simple meaning.

🟢 BFS Explore nearby locations first.
🔵 DFS Explore one possible route deeply.
🟠 Best First Prefer locations that look closer to the destination.
🟣 A* ⭐ Uses travelled distance and estimated remaining distance.
